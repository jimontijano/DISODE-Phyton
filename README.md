# Disode45 for Phyton

This file contains a function Phyton intended to solve ordinary differentials equations (ODEs) with non continuous vector field.

## Features

* The code integrates numerically the differential system in an automatic way, just providing the function containing the definition of the vector field and an additional function providing the manifolds where the vector field changes its definition (discontinuity manifolds).

* The code is able to integrate automatically equations where sliding regions (in the sense of Fi,lippov) can appear, with any number n of co-dimension situations (n meaning the simultaneous discontinuity manifold where the solution slides).

## Previous requirements:

* Python 3.8 or superior. 

## Instalation

1. Copy the file disode45.py from the repository:
